# CargoPilot Pro — финальная Telegram-CRM для карго

**CargoPilot Pro** — Telegram-CRM для карго-компаний по СНГ. Проект работает без веб-панели, без OpenAI/Gemini, без WhatsApp API и без других платных сервисов. Оплата нужна только за сервер.

## Что это

Система внутри Telegram для клиентов, менеджеров, склада, курьеров и владельца.

Клиент может оставить заявку, получить номер груза, проверить статус, создать обращение в поддержку и получить уведомления.

Менеджер/админ может вести заявки, статусы, оплаты, долги, жалобы, поддержку, тарифы, партнёров, курьеров и отчёты.

## Главное улучшение в этой версии

Автостатусы теперь работают максимально просто:

- новые заявки автоматически получают маршрут и автостатусы;
- админ не обязан вручную включать автостатусы каждому грузу;
- для старых грузов можно нажать `🤖 Автостатусы` и ввести `ВСЕ`;
- бот сам определяет маршрут по направлению: Китай, Турция, ОАЭ/Дубай или СНГ;
- бот сам меняет статус по расписанию и уведомляет клиента;
- всё работает бесплатно, без внешних API.

## Как работают бесплатные автостатусы

Маршруты:

```text
china_cis — Китай → СНГ
turkey_cis — Турция → СНГ
uae_cis — Дубай/ОАЭ → СНГ
cis_local — СНГ → СНГ
```

В реальной работе:

```text
AUTO_STATUS_TIME_UNIT=days
```

В демо-режиме:

```text
AUTO_STATUS_TIME_UNIT=minutes
```

Если `AUTO_STATUS_ON_NEW_ORDERS=true`, новые заявки сразу получают автостатусы. Для старых заказов админ может:

```text
/admin → 🤖 Автостатусы → ВСЕ
```

или командой:

```text
/autostatus_all on
```

## Техподдержка

1. Клиент нажимает `🛠️ Техподдержка`.
2. Создаёт обращение.
3. Указывает номер груза или `0`, если вопрос общий.
4. Выбирает тему.
5. Описывает вопрос.
6. Админ получает тикет.
7. Админ отвечает кнопкой или командой `/replyticket`.
8. Клиент может дописать в обращение.
9. Админ закрывает тикет.

## Почему почти бесплатно

Не используются платные API:

- Telegram Bot API — бесплатно;
- SQLite — бесплатно;
- Excel через openpyxl — бесплатно;
- QR через qrcode — бесплатно;
- PDF через reportlab — бесплатно;
- AI-логика — через сценарии, кнопки, FAQ, шаблоны и автостатусы.

## Автостатусы без команд

В этой версии админ не обязан вводить команды `/autostatus` или `/autoroute`.

Как включить:

1. Открыть `/admin`.
2. Нажать кнопку `🤖 Автостатусы`.
3. Нажать `✅ Включить всем активным грузам` или выбрать конкретный груз из списка.

Бот сам определяет маршрут по направлению груза:

- Китай → СНГ: `china_cis`
- Турция → СНГ: `turkey_cis`
- Дубай/ОАЭ → СНГ: `uae_cis`
- СНГ → СНГ: `cis_local`

После включения бот сам меняет статусы по расписанию и уведомляет клиента. Команды оставлены только как технический резерв для разработчика.

## CargoPilot SmartFlow — уникальная логика

В этой версии продукт усилен не просто как бот, а как система контроля карго:

- smart-карточка груза на веб-странице;
- история, оплата, фото и обращения по каждому грузу;
- партии грузов и массовая смена статуса;
- Problem Radar: система сама показывает проблемные грузы;
- ежедневный отчёт владельцу;
- кнопка “Задать вопрос по этому грузу” на странице отслеживания.

Это позволяет продавать продукт как систему управления грузами и партиями, а не как обычный Telegram-бот.


## CargoPilot TrustFlow — Anti-“Где мой груз?” система

В этой версии веб-трекинг показывает клиенту не просто статус, а понятную карточку:

- что означает текущий статус;
- какой следующий этап;
- когда ждать обновление;
- всё идёт по плану или есть задержка;
- нужна ли связь с менеджером;
- сколько раз клиент сам проверял груз.

Главная ценность: система снижает количество ручных вопросов “где мой груз?” и повышает доверие клиента к карго-компании.


## Demo Bank Payments

В демо добавлены варианты виртуальной оплаты: Kaspi, Halyk, ЦентрКредит и Freedom.

Это не настоящая оплата и деньги не списываются. Модуль нужен, чтобы показать клиенту сценарий:
страница груза → выбор банка → демо-оплата → заказ отмечается как оплаченный.

Для реального внедрения подключается официальный платёжный провайдер банка или эквайринг.


## Manual SmartFlow Report

Автоматическая отправка ежедневного отчёта владельцу выключена по умолчанию.

Теперь админ сам получает отчёт, когда нужно:

`/start` → `📊 SmartFlow отчёт`

Это сделано, чтобы бот не присылал отчёт сам после redeploy и не сбивал админское меню.


## Payment separate from tracker

Оплата вынесена отдельно от страницы отслеживания.

Теперь `/track/CG...` показывает только статус груза, TrustFlow-объяснение, следующий этап, историю, фото и обращения.

Оплата запускается отдельно через Telegram-кнопку:

`💳 Оплатить доставку`

После этого клиент вводит номер груза и выбирает демо-банк: Kaspi, Halyk, ЦентрКредит или Freedom.


## Admin payment notifications

После демо-оплаты админ получает уведомление в Telegram:

- номер груза;
- выбранный банк;
- сумма;
- статус оплаты;
- payment_id.

Также добавлена защита от двойного клика: одна и та же демо-оплата не начисляется дважды.
