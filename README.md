# CargoPilot Pro — финальная Telegram-CRM для карго

**CargoPilot Pro** — Telegram-CRM для карго-компаний по СНГ. Проект работает без веб-панели, без OpenAI/Gemini, без WhatsApp API и без других платных сервисов. Оплата нужна только за сервер.

## Что это

Система внутри Telegram для клиентов, менеджеров, склада, курьеров и владельца.

Клиент может оставить заявку, получить номер груза, проверить статус, создать обращение в поддержку и получить уведомления.

Менеджер/админ может вести заявки, статусы, оплаты, долги, жалобы, поддержку, тарифы, партнёров, курьеров и отчёты.

## Главное улучшение в этой версии

Автостатусы теперь работают максимально просто:

- новые заявки автоматически получают маршрут и автостатусы;
- админ не обязан вручную включать автостатусы каждому грузу;
- для старых грузов можно нажать `🤖 Автостатусы` и ввести `ВСЕ`;
- бот сам определяет маршрут по направлению: Китай, Турция, ОАЭ/Дубай или СНГ;
- бот сам меняет статус по расписанию и уведомляет клиента;
- всё работает бесплатно, без внешних API.

## Переменные окружения

Создай `.env` локально или добавь Variables на Railway/Render/Koyeb:

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=твой_telegram_id
WAREHOUSE_IDS=
COURIER_IDS=
COMPANY_NAME=CargoPilot Pro
DATA_DIR=/data
DB_PATH=/data/cargopilot.sqlite3
PORT=8080
CURRENCY=₸
PARTNER_COMMISSION_PERCENT=5
REGION_MODE=CIS
AUTO_STATUS_ENABLED=true
AUTO_STATUS_INTERVAL_SECONDS=300
AUTO_STATUS_TIME_UNIT=days
AUTO_STATUS_ON_NEW_ORDERS=true
```

Для демо, чтобы статусы менялись быстро, временно поставь:

```env
AUTO_STATUS_TIME_UNIT=minutes
AUTO_STATUS_INTERVAL_SECONDS=30
```

После демо верни:

```env
AUTO_STATUS_TIME_UNIT=days
AUTO_STATUS_INTERVAL_SECONDS=300
```

## Как работают бесплатные автостатусы

Маршруты:

```text
china_cis — Китай → СНГ
turkey_cis — Турция → СНГ
uae_cis — Дубай/ОАЭ → СНГ
cis_local — СНГ → СНГ
```

В реальной работе:

```text
AUTO_STATUS_TIME_UNIT=days
```

В демо-режиме:

```text
AUTO_STATUS_TIME_UNIT=minutes
```

Если `AUTO_STATUS_ON_NEW_ORDERS=true`, новые заявки сразу получают автостатусы. Для старых заказов админ может:

```text
/admin → 🤖 Автостатусы → ВСЕ
```

или командой:

```text
/autostatus_all on
```

## Техподдержка

1. Клиент нажимает `🛠️ Техподдержка`.
2. Создаёт обращение.
3. Указывает номер груза или `0`, если вопрос общий.
4. Выбирает тему.
5. Описывает вопрос.
6. Админ получает тикет.
7. Админ отвечает кнопкой или командой `/replyticket`.
8. Клиент может дописать в обращение.
9. Админ закрывает тикет.

## Почему почти бесплатно

Не используются платные API:

- Telegram Bot API — бесплатно;
- SQLite — бесплатно;
- Excel через openpyxl — бесплатно;
- QR через qrcode — бесплатно;
- PDF через reportlab — бесплатно;
- AI-логика — через сценарии, кнопки, FAQ, шаблоны и автостатусы.

## Автостатусы без команд

В этой версии админ не обязан вводить команды `/autostatus` или `/autoroute`.

Как включить:

1. Открыть `/admin`.
2. Нажать кнопку `🤖 Автостатусы`.
3. Нажать `✅ Включить всем активным грузам` или выбрать конкретный груз из списка.

Бот сам определяет маршрут по направлению груза:

- Китай → СНГ: `china_cis`
- Турция → СНГ: `turkey_cis`
- Дубай/ОАЭ → СНГ: `uae_cis`
- СНГ → СНГ: `cis_local`

После включения бот сам меняет статусы по расписанию и уведомляет клиента. Команды оставлены только как технический резерв для разработчика.
