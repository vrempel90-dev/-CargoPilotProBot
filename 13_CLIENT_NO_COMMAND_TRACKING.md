# Client No-Command Tracking

В этой версии клиенту не нужно вводить команды в Telegram, чтобы отслеживать груз.

## Как работает

1. Клиент оформляет доставку через меню.
2. Бот создаёт номер груза.
3. Бот сразу отправляет клиенту прямую ссылку:

```text
https://your-domain/track/CG26050500001
```

4. Клиент открывает ссылку в браузере и видит статус.
5. Менеджер меняет статусы через Telegram-админку.
6. Веб-страница показывает актуальный статус из базы.

## Что добавить в Railway

```env
PUBLIC_BASE_URL=https://cargopilotprobot-production.up.railway.app
```

Для клиента это выглядит как обычный сайт-трекинг: нажал ссылку — увидел статус.
