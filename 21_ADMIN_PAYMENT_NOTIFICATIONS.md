# Admin payment notifications

Добавлено:

- когда клиент проходит демо-оплату через Kaspi / Halyk / BCC / Freedom, админ получает уведомление в Telegram;
- уведомление содержит:
  - номер груза;
  - банк;
  - сумму;
  - статус оплаты;
  - сколько всего оплачено;
  - payment_id;
- защита от двойного клика: если одну и ту же демо-оплату открыть повторно, деньги второй раз не начисляются и повторное уведомление админу не уходит.

Сценарий:
1. клиент нажимает `💳 Оплатить доставку`;
2. выбирает банк;
3. нажимает `✅ Оплатить в демо`;
4. бот отмечает заказ как оплаченный;
5. админ получает сообщение `💳 Новая оплата`.
