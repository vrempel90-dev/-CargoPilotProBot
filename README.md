# CargoAI Manager

**CargoAI Manager** — Telegram-CRM для карго-компаний без веб-панели и без платных AI/API.

Проект работает только через Telegram:

- клиент — в Telegram-боте;
- менеджер — в Telegram или Telegram Desktop;
- склад — в Telegram;
- курьер — в Telegram;
- Excel — только для отчётов и массового обновления;
- сервер — только для запуска бота 24/7.

## Что умеет бот

1. Принимает заявки на доставку.
2. Показывает статус груза по номеру.
3. Отвечает на сценарий «Где мой груз?».
4. Считает примерную стоимость доставки.
5. Даёт складской модуль: вес, фото, статусы.
6. Принимает заявки на выкуп товара.
7. Подходит для байеров одежды и товаров.
8. Принимает оптовые заявки.
9. Даёт чек-лист по документам.
10. Уведомляет клиента при смене статуса.
11. Принимает жалобы.
12. Считает цену, оплаты, долги и маржу.
13. Даёт партнёрские ссылки и отчёты.
14. Генерирует QR-код груза.
15. Делает PDF-квитанцию.
16. Экспортирует заказы в Excel.
17. Обновляет статусы массово через Excel.
18. Поддерживает роли: клиент, админ, склад, курьер, партнёр.
19. Даёт полноценную техподдержку через тикеты: клиент создаёт обращение, админ отвечает, клиент может дописать, обращение можно закрыть.

## Установка локально

```bash
pip install -r requirements.txt
```

Создай файл `.env` по примеру `.env.example`:

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=твой_telegram_id
COMPANY_NAME=CargoAI Manager
DATA_DIR=.
DB_PATH=./cargo_ai_crm.sqlite3
PORT=8080
CURRENCY=$
```

Запуск:

```bash
python main.py
```

## Как работает техподдержка

Техподдержка сделана не как простая кнопка, а как тикетная система:

1. Клиент нажимает `🛠️ Техподдержка`.
2. Выбирает `🆕 Создать обращение`.
3. Указывает номер груза или пишет `0`, если вопрос общий.
4. Выбирает тему: груз, оплата, повреждение/фото, ошибка в боте или другое.
5. Описывает вопрос.
6. Админ получает карточку обращения с кнопками `💬 Ответить` и `✅ Закрыть`.
7. Ответ админа приходит клиенту в Telegram.
8. Клиент может открыть `📋 Мои обращения` и дописать сообщение в тот же тикет.

Команды для админа:

```text
/support — список открытых обращений
/replyticket 1 текст ответа — ответить клиенту
/closeticket 1 — закрыть обращение
```

## Почему почти бесплатно

Не используются платные AI/API:

- Telegram Bot API — бесплатно;
- SQLite — бесплатно;
- Excel через openpyxl — бесплатно;
- QR через qrcode — бесплатно;
- PDF через reportlab — бесплатно;
- AI-логика — через кнопки, сценарии, FAQ и шаблоны.
