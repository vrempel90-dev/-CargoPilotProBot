# Payment separate from tracker

Исправление:

- в `/track/CG...` больше нет кнопки оплаты;
- в Smart-карточке груза больше нет блока оплаты;
- страница отслеживания теперь показывает только статус, объяснение, следующий этап, историю, фото и обращения;
- оплата открывается отдельно через кнопку в Telegram: `💳 Оплатить доставку`;
- демо-банки Kaspi / Halyk / BCC / Freedom остались, но не смешаны с трекингом.

Сценарий теперь такой:

1. Клиент хочет проверить груз → открывает ссылку `/track/CG...`.
2. Клиент хочет оплатить → в Telegram нажимает `💳 Оплатить доставку`.
3. Бот просит номер груза.
4. Бот даёт отдельную кнопку `Выбрать способ оплаты`.
5. Клиент выбирает Kaspi / Halyk / BCC / Freedom в демо-режиме.

Так трекер не выглядит как платёжная страница, а оплата остаётся отдельным процессом.
