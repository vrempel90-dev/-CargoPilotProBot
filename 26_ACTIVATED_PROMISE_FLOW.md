# Activated Promise Flow

Исправление: функции CargoPromise теперь задействованы прямо в рабочем сценарии.

## Новая логика

### Для клиента
После оформления заявки клиент получает не старое сообщение, а CargoPromise-сообщение:

- номер груза `CG...`;
- Promise ID `CP-...`;
- безопасное обещание по сроку;
- от какого события считать срок;
- что нельзя обещать;
- кнопку `🧾 Открыть Promise Passport`.

### Для админа
Новая заявка приходит не как обычная карточка, а как:

- Promise ID;
- Risk Gate;
- TrustScore;
- Anxiety Score;
- безопасное обещание;
- предупреждение: автостатусы только после оплаты.

### В админских кнопках
На новой заявке есть:

- `🧭 Promise Card`;
- `💳 Напомнить об оплате`;
- `🔁 Изменить статус`;
- `⚠️ Проблема`.

### После оплаты
Админу приходит уведомление об оплате, после этого он может открыть Promise Card и включить автостатусы.

Теперь Promise OS видно сразу, а не только через отдельную кнопку в админке.
