# Tracker only details

Исправление логики уведомлений:

Раньше Telegram сам писал клиенту:
- новый статус;
- комментарий;
- кнопку трекера.

Из-за этого веб-трекер казался лишним.

Теперь Telegram отправляет только короткое уведомление:
`Есть обновление по грузу CG...`

А все подробности находятся только на странице отслеживания:
- текущий статус;
- что статус означает;
- следующий этап;
- ожидаемое обновление;
- история статусов;
- фото;
- обращения;
- индикатор TrustFlow.

Правильная логика продукта:
Telegram = уведомление.
Web tracker = подробная карточка груза.
