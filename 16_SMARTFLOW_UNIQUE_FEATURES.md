# CargoPilot SmartFlow — уникальные функции

Добавлено 7 функций, чтобы продукт был не просто ботом:

1. Smart-карточка груза на веб-странице `/track/CG...`
   - статус
   - история
   - оплата / долг
   - фото
   - обращения

2. Партии грузов как главная логика карго.

3. Массовое обновление статуса партии.

4. SmartFlow Problem Radar:
   - грузы давно без обновления
   - грузы без веса
   - грузы с долгом
   - открытые жалобы
   - открытые тикеты поддержки

5. Ежедневный отчёт владельцу.

6. Напоминания об оплате остаются в CRM.

7. Кнопка `Задать вопрос по этому грузу` на странице отслеживания.

Новые переменные:
```env
ISSUE_STALE_HOURS=24
OWNER_REPORT_ENABLED=true
OWNER_REPORT_INTERVAL_SECONDS=86400
BOT_USERNAME=CargoPilotProBot
```

Теперь продукт лучше продавать не как Telegram-бот, а как:

CargoPilot SmartFlow — система отслеживания грузов, партий и проблемных заказов для карго-компаний.
