# Payment → Admin notification → Auto statuses

Новая логика работы:

1. Клиент оформляет доставку.
2. Бот создаёт груз и номер CG...
3. Автостатусы НЕ включаются сразу.
4. Клиент оплачивает доставку через отдельную кнопку `💳 Оплатить доставку`.
5. Админу приходит уведомление:
   `💳 Новая оплата`
6. В этом уведомлении есть кнопка:
   `🤖 Включить автостатусы`
7. Только после нажатия админом бот начинает вести груз по маршруту и менять статусы.

Что важно:
- новая заявка больше не получает автостатусы автоматически;
- кнопка автостатусов в новой заявке скрыта;
- включить автостатусы до оплаты нельзя;
- массовое включение автостатусов включает их только для оплаченных грузов.

Railway variables:
```env
AUTO_STATUS_ON_NEW_ORDERS=false
AUTO_STATUS_AFTER_PAYMENT_ONLY=true
```
