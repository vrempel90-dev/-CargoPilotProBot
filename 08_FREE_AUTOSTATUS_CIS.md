# Бесплатные автостатусы СНГ

Автостатусы работают без платных API. Бот сам меняет статус груза по расписанию выбранного маршрута и уведомляет клиента.

## Что улучшено

Теперь автостатусы можно использовать без ручной настройки каждого заказа:

1. Новые заявки автоматически получают маршрут и автостатусы, если включено:

```env
AUTO_STATUS_ON_NEW_ORDERS=true
```

2. Для старых активных грузов можно включить автостатусы сразу всем:

```text
/admin → 🤖 Автостатусы → ВСЕ
```

или командой:

```text
/autostatus_all on
```

3. Для одного груза всё ещё можно включить отдельно:

```text
/autostatus CG26050300001 on
```

## Маршруты

```text
china_cis — Китай → СНГ
turkey_cis — Турция → СНГ
uae_cis — Дубай/ОАЭ → СНГ
cis_local — СНГ → СНГ
```

Бот сам определяет маршрут по полям заявки: страна отправки и город/страна назначения.

## Реальная работа

```env
AUTO_STATUS_TIME_UNIT=days
AUTO_STATUS_INTERVAL_SECONDS=300
```

Статусы будут меняться по дням маршрута.

## Демо для клиента

```env
AUTO_STATUS_TIME_UNIT=minutes
AUTO_STATUS_INTERVAL_SECONDS=30
```

Статусы будут меняться по минутам, чтобы быстро показать клиенту автоматизацию.

После демо верни `AUTO_STATUS_TIME_UNIT=days`.

## Важно

Автостатусы — это бесплатная автоматизация по расписанию. Это не интеграция с реальным складом, Kaspi, WhatsApp или внешней CRM.

Если у клиента есть своя система или API, это можно подключить отдельным платным этапом.
