# CargoPilot Web Track

Это модуль для клиентов, которым Telegram не подходит как основной канал.

## Что добавлено

- публичная страница `/track`;
- проверка груза по номеру через браузер;
- история статусов;
- мобильная адаптация;
- API `/api/track/CG...`;
- возможность поставить ссылку на сайт клиента;
- возможность встроить страницу через iframe.

## Как выглядит логика

Клиент не открывает Telegram. Он заходит на сайт компании и вводит номер груза.

Менеджер при этом продолжает работать через Telegram-админку: меняет статусы, ведёт партии, оплаты, склад и техподдержку.

## Почему это дороже

Потому что продукт закрывает уже две задачи:

1. внутреннее управление грузами через Telegram;
2. публичное отслеживание груза на сайте.

Это можно продавать за 500–700$.

## Что сказать клиенту

> Если у вас уже есть сайт, можно не делать Telegram основным каналом для клиентов. Мы добавим страницу отслеживания груза на сайт: клиент вводит номер и видит статус. А сотрудники управляют всем через Telegram-админку.
