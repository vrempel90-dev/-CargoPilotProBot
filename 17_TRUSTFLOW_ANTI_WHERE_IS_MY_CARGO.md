# CargoPilot TrustFlow

Это обновление делает продукт уникальнее обычного сайта, CRM или Telegram-бота.

Главная идея:
клиент видит не просто статус, а понятное объяснение, следующий этап и нужно ли писать менеджеру.

Что добавлено:

1. Индикатор спокойствия:
   - 🟢 Всё идёт по плану
   - 🟡 Возможна задержка
   - 🔴 Нужна проверка менеджером

2. Объяснение статуса человеческим языком.

3. Следующий ожидаемый этап.

4. Ожидаемая дата / время следующего обновления.

5. Кнопка поддержки появляется только когда есть причина:
   задержка, проблема или финальный этап.

6. Счётчик просмотров страницы груза.
   Владелец видит, сколько раз клиенты сами проверяли статус.

7. Ежедневный отчёт владельцу показывает:
   - заявки
   - оборот
   - маржу
   - самопроверки грузов
   - проблемные грузы
   - долги
   - жалобы
   - тикеты

Позиционирование:
CargoPilot TrustFlow — Anti-“Где мой груз?” система для карго-компаний.

Новые переменные:
```env
TRUSTFLOW_ENABLED=true
TRUSTFLOW_GRACE_HOURS=12
BOT_USERNAME=CargoPilotProBot
```
